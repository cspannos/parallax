# Security

Parallax is a **research prototype**. It has not been audited, and it is not intended to hold, move or secure real assets. Do not deploy it in production or connect it to real funds.

## Known limitations

The prototype's known security gaps and open questions are tracked openly, not hidden:

- [Known gaps (v1 prototype)](docs/open-questions.md#known-gaps-v1-prototype)
- [Threat model](docs/threat-model.md)
- [Post-quantum status](docs/post-quantum.md): the hybrid suites are experimental, built on pre-1.0 libraries, and the network is **not** post-quantum secure.

## Reporting an issue

Design flaws and bugs are welcome as GitHub issues, since there is no production deployment to protect. If you believe a finding should not be public (for example, it affects an upstream library), use GitHub's private vulnerability reporting for this repository instead.

There is no bug bounty.
